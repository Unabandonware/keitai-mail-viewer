# keitai-mail-viewer
A tool for reading email templates used in Japanese feature phones.

It is currently compatible with NTT DoCoMo decome templates saved in a .dmt file format. It can also read email drafts saved as .vmg files.

[Click here for the Keitai Mail Viewer](https://unabandonware.github.io/keitai-mail-viewer/).

# About Deco-mail 
Deco-mail (デコメール), also known as Decome (デコメ), is an i-mode service that enabled users to create customized emails with animated gifs, HTML templates, and in-line Flash.

The Deco-mail viewer in this Javascript application is based on NTT DoCoMo's 
i-mode HTML Simulator II application.

# About Decome-Anime (not yet implemented)
Decome Anime (デコメアニメ) is a type of Deco-mail template that uses Flash to create interactive emails with customized messages.
